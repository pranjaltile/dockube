# 🚀 DevOps Learning Hub

A hands-on collection of DevOps projects built to learn and practice modern containerization, orchestration, cloud-native, and infrastructure technologies.

This repository follows a project-based learning approach where each project introduces new concepts, tools, and real-world workflows used in modern DevOps environments.

---

## 🎯 Repository Objectives

- Learn DevOps concepts through practical implementation
- Build production-like environments locally
- Understand end-to-end application deployment workflows
- Document learnings in a structured and reusable format
- Create a personal DevOps knowledge repository

---

## 📚 Projects

### 🐳 Project 1 — Docker & Harbor Registry

Containerize a Python Flask application and manage container images using a private Harbor registry.

#### Topics Covered
- Docker Fundamentals
- Docker Images & Containers
- Dockerfile
- Image Tagging & Versioning
- Harbor Registry
- Docker Desktop + WSL Integration
- Private Image Management

📖 Documentation:

👉 [Project 1 - Docker & Harbor](./docker-project/README_docker.md)

---

### ☸️ Project 2 — Kubernetes & APISIX Gateway

Deploy the Dockerized application to Kubernetes using Minikube and expose it through APISIX API Gateway.

#### Topics Covered

- Kubernetes Architecture
- Pods
- Deployments
- Services
- ClusterIP
- Helm
- APISIX Gateway
- Load Balancing
- Routing
- Port Forwarding
- Kubernetes Networking

📖 Documentation:

👉 [Project 2 - Kubernetes & APISIX](./kubernetes-project/README_kubernetes.md)
